# Google Earth Pro

Репозиторий с установочным файлом Google Earth Pro для Windows.

## Как установить

1. Перейдите в раздел **[Releases](https://github.com/grabchevsky/Google-Earth-Pro/releases)**.
2. Скачайте установочный файл `GoogleEarthProSetup-wojtek.exe`.
3. Запустите файл и следуйте инструкциям мастера установки.

## Системные требования

*   **ОС:** Windows 10 или 11 (64-bit).
*   **Интернет:** Обязательно наличие подключения к сети. Программа загружает спутниковые снимки и карты с серверов Google в реальном времени.

## Примечание

Программа не требует сложной настройки. После установки просто запустите её и введите нужный адрес или координаты в строке поиска.
